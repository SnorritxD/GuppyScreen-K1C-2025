# GuppyScreen-K1C-2025

GuppyScreen build voor de Creality K1C 2025/2026.

## Hardware

- Printer: Creality K1C 2025/2026
- SoC: X2600
- Display framebuffer: fb1
- Touch input: event1
- Architecture: MIPS32 little endian

## Installatie

Kopieer of clone deze repo naar de printer:

```sh
cd /usr/data
git clone https://github.com/SnorritxD/GuppyScreen-K1C-2025.git guppyscreen
cd guppyscreen
chmod +x install.sh
./install.sh
